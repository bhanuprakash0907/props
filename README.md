# React Lab: Props, State, Events, and Styling

A small interactive React app for demonstrating core frontend concepts.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite in a browser.

## What to demonstrate

- **Props:** `TaskItem` receives a task and callback functions from `App`.
- **State:** `useState` manages the counter, task list, input, and accent color.
- **Events:** Buttons, checkboxes, and the form update the app.
- **Styling:** CSS classes and accent colors update the appearance.
